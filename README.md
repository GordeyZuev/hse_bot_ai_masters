# Бот - оповещатель ИИ

Телеграм бот для уведомлений о дедлайнах студентов магистратуры ВШЭ по направлению "Искусственный интеллект". Бот интегрируется с Google Sheets для синхронизации данных о дедлайнах и предоставляет полнофункциональную систему подписок и уведомлений.

## 🚀 Основные возможности

- **Система подписок** - подписка на предметы и управление подписками
- **Уведомления о дедлайнах** - настраиваемые уведомления (минимум за 30 минут до дедлайна)
- **Просмотр дедлайнов** - отображение дедлайнов с цветовой индикацией по срочности
- **Настройки уведомлений** - гибкая настройка времени и типов уведомлений
- **Административная панель** - статистика, массовые рассылки, управление логами
- **Синхронизация с Google Sheets** - автоматическое обновление данных о дедлайнах
- **Многопользовательская система** - поддержка неограниченного количества пользователей

## 🤖 Команды бота

### Пользовательские команды

| Команда | Описание |
|---------|----------|
| `/start` | Запуск бота и главное меню |
| `/help` | Подробная справка по использованию |
| `/sub` | Подписаться на предмет |
| `/unsub` | Отписаться от предмета |
| `/unsuball` | Отписаться от всех предметов |
| `/mysubs` | Показать все активные подписки |
| `/deadlines [N]` | Дедлайны на N дней (по умолчанию 15) |
| `/settings` | Настройки уведомлений |

### Административные команды

| Команда | Описание | Доступ |
|---------|----------|--------|
| `/admin` | Административная панель | Только админы |
| `/stats` | Статистика использования бота | Только админы |
| `/broadcast` | Массовая рассылка сообщений | Только админы |
| `/logs` | Получить файлы логов | Только админы |

## ⚙️ Установка и настройка

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd hse_bot_ai_masters
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Создайте файл `src/config/.env` со следующими переменными:

```env
# Telegram Bot
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_IDS=123456789,987654321  # ID администраторов через запятую

# Database
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/hse_bot

# Google Sheets
GOOGLE_SHEETS_URL=https://docs.google.com/spreadsheets/d/your_sheet_id/edit
GOOGLE_CREDENTIALS_PATH=path/to/your/credentials.json

# External Links
FCS_WIKI_URL=https://wiki.cs.hse.ru/
GOOGLE_SHEETS_LINK=https://docs.google.com/spreadsheets/d/your_sheet_id/edit

# Logging
LOG_LEVEL=INFO
LOG_FILE_PATH=logs/bot.log
SYNC_LOG_FILE_PATH=logs/sync.log

# Timezone
TIMEZONE=Europe/Moscow

# Notification Settings
NOTIFICATION_DAYS_BEFORE=3,1,0  # За сколько дней уведомлять (устаревшее)
NOTIFICATION_TIME=09:00  # Время уведомлений (HH:MM, устаревшее)
SYNC_INTERVAL_HOURS=1    # Интервал синхронизации в часах
NOTIFICATION_CHECK_MINUTES=5  # Интервал проверки уведомлений в минутах
```

### 4. Настройка базы данных

```bash
# Создание миграций (если нужно)
alembic revision --autogenerate -m "Initial migration"

# Применение миграций
alembic upgrade head
```

### 5. Настройка Google Sheets API

1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включите Google Sheets API
3. Создайте Service Account и скачайте JSON-файл с ключами
4. Укажите путь к файлу в переменной `GOOGLE_CREDENTIALS_PATH`
5. Предоставьте доступ к таблице для email из Service Account

```bash

```

## 🏗️ Архитектура

### Основные компоненты

1. **Bot Layer** (`src/bot/`)
   - Обработчики команд и callback'ов
   - FSM для управления состояниями пользователя
   - Middleware для автоматического управления пользователями
   - Сервисы для бизнес-логики бота

2. **Core Layer** (`src/core/`)
   - Модели данных (SQLAlchemy)
   - Менеджер базы данных
   - Система синхронизации с Google Sheets
   - Планировщик задач

3. **Utils Layer** (`src/utils/`)
   - Система логирования
   - Вспомогательные утилиты

### Паттерны проектирования

- **Service Layer** - бизнес-логика вынесена в отдельные сервисы
- **Repository Pattern** - абстракция работы с базой данных
- **Middleware Pattern** - обработка запросов через промежуточное ПО
- **FSM (Finite State Machine)** - управление состояниями пользователя
- **Dependency Injection** - внедрение зависимостей через middleware

### База данных

Используется PostgreSQL с SQLAlchemy 2.0 (async). Основные таблицы:

- `users` - пользователи бота
- `subjects` - предметы
- `deadlines` - дедлайны
- `subscriptions` - подписки пользователей
- `notifications` - история уведомлений

## 🔧 Разработка

### Добавление новых команд

1. Создайте handler в соответствующем файле в `src/bot/handlers/`
2. Зарегистрируйте router в `src/bot/bot.py`
3. При необходимости добавьте новые состояния в `src/bot/states/states.py`

### Добавление новых сервисов

1. Создайте сервис в `src/bot/services/`
2. Реализуйте необходимую бизнес-логику
3. Интегрируйте с handlers через dependency injection

### Миграции базы данных

```bash
# Создание новой миграции
alembic revision --autogenerate -m "Description of changes"

# Применение миграций
alembic upgrade head

# Откат миграции
alembic downgrade -1
```
