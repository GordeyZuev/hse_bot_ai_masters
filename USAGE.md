# HSE Bot - Руководство по использованию

## Описание
HSE Bot - телеграм бот для уведомлений о дедлайнах на магистратуре ВШЭ. Бот автоматически синхронизирует данные из Google Sheets и отправляет персонализированные уведомления пользователям.

## Запуск бота

### Режимы запуска:

1. **Полный режим (рекомендуется):**
   ```bash
   python main.py full
   ```
   Запускает бота с синхронизацией данных и системой уведомлений.

2. **Только бот:**
   ```bash
   python main.py bot
   ```
   Запускает только телеграм бота без синхронизации.

3. **Только синхронизация:**
   ```bash
   python main.py sync
   ```
   Выполняет одну синхронизацию данных и завершает работу.

4. **Планировщик синхронизации:**
   ```bash
   python main.py scheduler
   ```
   Запускает только планировщик синхронизации без бота.

## Команды пользователей

### Основные команды:
- `/start` - Запуск бота, короткая справка
- `/help` - Подробная информация о боте

### Управление подписками:
- `/sub` - Подписаться на предметы
- `/unsub` - Отписаться от предмета
- `/unsuball` - Отписаться от всех предметов
- `/mysubs` - Показать все подписки

### Дедлайны:
- `/deadlines` - Дедлайны на 15 дней (по умолчанию)
- `/deadlines 7` - Дедлайны на 7 дней
- `/deadlines 30` - Дедлайны на 30 дней

### Настройки:
- `/settings` - Настройки уведомлений

## Команды администраторов

### Статистика и управление:
- `/stats` - Статистика использования бота
- `/broadcast` - Массовая рассылка сообщений

## Функциональность

### Подписки на предметы
1. Используйте `/sub` для выбора курса (1 или 2)
2. Выберите предметы для подписки
3. Управляйте подписками через `/mysubs`, `/unsub`, `/unsuball`

### Настройка уведомлений
1. Откройте `/settings`
2. Настройте до 2 уведомлений на пользователя
3. Выберите время: за N дней/часов/минут до дедлайна
4. Включайте/выключайте уведомления по необходимости

### Просмотр дедлайнов
- `/deadlines` показывает дедлайны только по подписанным предметам
- Поддерживаются мягкие и жесткие дедлайны
- Отображается время до дедлайна
- Ссылки на задания (если есть)

## Автоматические процессы

### Синхронизация данных:
- Каждый час синхронизируются данные из Google Sheets
- Обновляются дедлайны и информация о предметах
- Удаляются устаревшие дедлайны

### Система уведомлений:
- Каждые 30 минут проверяются приближающиеся дедлайны
- Отправляются персонализированные уведомления
- Ведется лог отправленных уведомлений

### Очистка данных:
- Ежедневно в 3:00 очищаются старые логи
- Удаляются записи старше 30 дней

## Настройка окружения

### Переменные в .env файле:
```env
# Telegram Bot
BOT_TOKEN=your_bot_token
ADMINS=[admin_user_id1,admin_user_id2]

# Database
DATABASE_URL=postgresql+asyncpg://user:password@host:port/database
DB_HOST=localhost
DB_PORT=5432
DB_NAME=hse_bot_db
DB_USER=postgres
DB_PASSWORD=password

# Google Sheets
GOOGLE_SHEETS_URL=your_google_sheets_url
GOOGLE_CREDS_FILE=src/config/creds.json

# Logging
LOG_LEVEL=INFO
LOG_DIR=logs
```

### Требования:
- Python 3.8+
- PostgreSQL
- Google Sheets API credentials
- Telegram Bot Token

## Архитектура

### Структура проекта:
```
├── main.py                     # Точка входа
├── src/
│   ├── bot/                    # Телеграм бот
│   │   ├── handlers/           # Обработчики команд
│   │   ├── middlewares/        # Middleware
│   │   └── services/           # Бизнес-логика
│   ├── core/                   # Ядро системы
│   │   ├── database/           # Работа с БД
│   │   ├── models/             # Модели данных
│   │   └── sync/               # Синхронизация
│   ├── config/                 # Конфигурация
│   └── utils/                  # Утилиты
└── logs/                       # Логи
```

### Основные компоненты:
- **HSEBot** - основной класс бота
- **DatabaseManager** - управление базой данных
- **DataSyncer** - синхронизация с Google Sheets
- **NotificationSender** - отправка уведомлений
- **BotScheduler** - планировщик задач

## Устранение неполадок

### Частые проблемы:
1. **Бот не отвечает** - проверьте BOT_TOKEN
2. **Нет данных о дедлайнах** - проверьте Google Sheets URL и credentials
3. **Не работают уведомления** - проверьте настройки пользователей
4. **Ошибки БД** - проверьте подключение к PostgreSQL

### Перезапуск:
```bash
# Остановить (Ctrl+C)
# Затем запустить снова
python main.py full
```

3. При необходимости добавьте сервис в `src/bot/services/`
