## 📅 Просмотр и отметка дедлайнов

В личном чате откройте `/deadlines`: по умолчанию это дедлайны на 7 дней. Кнопки переключают на 15 дней или на все будущие дедлайны. Выполненные задания можно показать или скрыть. В обычном режиме список и его навигация остаются привычными; «Отметить выполненные» открывает выбор конкретного задания, а не отмечает все разом.

В карточке задания нажмите «Отметить выполненным». Чтобы снять отметку, откройте задание и нажмите «Вернуть в работу». Повторное нажатие старой кнопки не должно случайно менять состояние обратно: откройте свежий экран. После выполнения запланированные напоминания по заданию отменяются, после возврата в работу — перепланируются.

Если администратор включил `RICH_MESSAGES_ENABLED=true`, в `/settings` можно выбрать экспериментальный Rich-режим. В нём таблица показывает «Дисциплина | Задание | Дедлайн» без нумерации; раскройте задание, чтобы увидеть ссылку, оставшееся время, другую дату и комментарий, если они есть. Кнопка отметки находится внутри раскрытого задания, а переключение страниц появляется под сообщением только при более чем 15 заданиях. Если Telegram не принимает Rich-сообщение, бот показывает обычный список. При выключенном флаге выбор Rich скрыт.

## 🤖 **Добавление бота в групповой чат**

Бот поддерживает два режима работы в групповых чатах:

### **Single-mode (одна дисциплина на весь чат)**

В этом режиме весь чат отслеживает дедлайны одной дисциплины. Настройка применяется ко всему чату сразу.

**📝 Пошаговая инструкция:**

1. **Добавьте бота в чат**
   - Откройте настройки группы/супергруппы
   - Перейдите в раздел "Участники" → "Добавить участников"
   - Найдите бота по имени и добавьте его
   - **Важно:** Убедитесь, что бот имеет права администратора (рекомендуется включить "Управление темами форума" для работы с закрытыми топиками)

2. **Настройте бота**
   - В общем чате или в любом топике вызовите команду `/start` или нажмите кнопку "⚙️ Настроить бота"
   - Выберите режим **"1️⃣ Single-mode"**
   - Выберите предмет из списка доступных дисциплин
   - При необходимости настройте параметры уведомлений:
     - Первое напоминание (по умолчанию: за 7 дней)
     - Второе напоминание (по умолчанию: за 1 день)
   - Нажмите "✅ Готово"

3. **Готово!**
   - Бот начнет отправлять уведомления о дедлайнах выбранной дисциплины
   - Все топики будут получать одинаковые уведомления

**💡 Полезные команды:**
- `/chat_settings` — просмотр и изменение настроек чата
- `/info` — информация о предмете и актуальные дедлайны
- `/disable_chat` — временно отключить уведомления в чате

---

### **Multi-mode (каждая дисциплина в своем топике)**

В этом режиме каждый топик может отслеживать дедлайны своей дисциплины. Настройка выполняется отдельно для каждого топика.

**📝 Пошаговая инструкция:**

1. **Добавьте бота в чат**
   - Откройте настройки группы/супергруппы
   - Перейдите в раздел "Участники" → "Добавить участников"
   - Найдите бота по имени и добавьте его
   - **Важно:** Убедитесь, что бот имеет права администратора (обязательно включите "Управление темами форума" для работы с топиками)

2. **Выберите режим Multi-mode**
   - В общем чате вызовите команду `/start` или нажмите кнопку "⚙️ Настроить бота"
   - Выберите режим **"2️⃣ Multi-mode"**
   - Бот подтвердит установку режима

3. **Настройте каждый топик отдельно**
   - Перейдите в нужный топик: в Multi-mode общий чат нельзя привязать к дисциплине
   - Вызовите команду `/setup_discipline` или нажмите кнопку "⚙️ Настроить бота" из `/start`
   - Выберите предмет для этого топика
   - При необходимости настройте параметры уведомлений:
     - Первое напоминание (по умолчанию: за 7 дней)
     - Второе напоминание (по умолчанию: за 1 день)
   - Нажмите "✅ Готово"

4. **Повторите для других топиков**
   - Для каждого топика, где нужны уведомления, выполните шаг 3
   - Каждый топик может отслеживать свою дисциплину независимо

**💡 Полезные команды:**
- `/start` в общем чате — просмотр всех настроенных топиков
- `/chat_settings` в топике — настройки конкретного топика
- `/info` — информация о предмете и дедлайны для текущего топика

**⚠️ Важно:**
- В Multi-mode нельзя настраивать общий чат — настройка выполняется только в топиках
- При переключении из Single-mode в Multi-mode все текущие настройки будут удалены, и нужно будет настроить каждый топик заново

## 📊 **Работа с таблицей дедлайнов**

Бот синхронизирует данные из `Google Sheets`. Для корректной работы важно правильно заполнять таблицу.

### Структура таблицы

Таблица дедлайнов должна содержать следующие колонки:

| Колонка | Описание | Обязательность |
|---------|----------|----------------|
| **ID** | Глобально уникальный положительный идентификатор | ✅ **Обязательно** |
| **Дисциплина** | Название предмета | ✅ Обязательно |
| **Название ДЗ** | Название задания | ✅ Обязательно |
| **Источник (Link)** | Ссылка на задание | ⚠️ Рекомендуется |
| **Мягкий Дедлайн** | Дата мягкого дедлайна | ⚠️ Нужна хотя бы одна дата |
| **Жесткий Дедлайн** | Дата жёсткого дедлайна | ⚠️ Нужна хотя бы одна дата |
| **До мягкого** | Оставшееся время до мягкого дедлайна | 🤖 Автоматически |
| **До жесткого** | Оставшееся время до жесткого дедлайна | 🤖 Автоматически |
| **Комментарий** | Дополнительная информация | ❌ Опционально |

**⚠️ Важно: названия столбцов менять нельзя!**

Бот находит данные по точным названиям столбцов в первой строке листа (например, `Дисциплина`, `Название ДЗ`, `Мягкий Дедлайн` и т.д.). Если переименовать столбец, бот перестанет его распознавать и данные из него не будут загружаться. В Google Таблице по умолчанию стоит предупреждение о запрете изменения названий столбцов.

**⚠️ Важность колонки ID:**

Колонка ID является **критически важной** для корректной работы синхронизации. Бот использует ID для:

1. **Идентификации дедлайнов** — определение, является ли строка новым дедлайном или обновлением существующего
2. **Обновления данных** — при изменении информации в строке бот находит соответствующий дедлайн по ID и обновляет его
3. **Удаления устаревших заданий** — если строка с ID исчезла из корректно прочитанного листа, запись удаляется вместе с зависимыми отметками и уведомлениями

**Что происходит без ID:** строка считается невалидной, пропускается и попадает в отчёт синхронизации. Бот не генерирует ID из содержимого строки.

**Рекомендации по ID:**
- Используйте нумерацию с привязкой к курсу:
  - **1 курс** — ID начинаются с `1000` (1000, 1001, 1002, ...)
  - **2 курс** — ID начинаются с `2000` (2000, 2001, 2002, ...)
- **Никогда не изменяйте ID существующей строки** — это приведет к созданию дубликата
- ID должен быть уникален сразу в обоих листах дедлайнов; удобная схема — `1001...` для первого курса и `2001...` для второго
- При удалении строки бот физически удаляет задание; повторное добавление того же ID создаст новое задание без прежних отметок выполнения
- При добавлении новой строки используйте следующий по порядку ID в диапазоне соответствующего курса

**Пример заполнения (1 курс):**

| ID | Дисциплина | Название ДЗ | Источник (Link) | Мягкий Дедлайн | Жесткий Дедлайн | До мягкого | До жесткого | Комментарий |
|----|------------|------------|-----------------|----------------|-----------------|------------|-------------|-------------|
| 1000 | Прикладной Python | Домашнее задание 1 | https://... | 15.12.2025 | 20.12.2025 | *авто* | *авто* | Важно! |
| 1001 | Машинное обучение | Проект | https://... | 25.12.2025 | 30.12.2025 | *авто* | *авто* | |

**Пример заполнения (2 курс):**

| ID | Дисциплина | Название ДЗ | Источник (Link) | Мягкий Дедлайн | Жесткий Дедлайн | До мягкого | До жесткого | Комментарий |
|----|------------|------------|-----------------|----------------|-----------------|------------|-------------|-------------|
| 2000 | Продвинутый Python | Лабораторная 1 | https://... | 15.12.2025 | 20.12.2025 | *авто* | *авто* | |
| 2001 | Глубокое обучение | Проект | https://... | 25.12.2025 | 30.12.2025 | *авто* | *авто* | |

### **Важные правила заполнения**

1. **Названия дисциплин должны совпадать**
   - Название в колонке "Дисциплина" должно точно совпадать с названием предмета в таблице "Дисциплины"
   - В Google Таблице дисциплина подставляется автоматически через выпадающий список — просто выберите нужное значение из списка
   - Сопоставление выполняется после удаления пробелов по краям, без алиасов и нечёткого поиска
   - Если дисциплина не найдена, дедлайн будет пропущен при синхронизации

2. **Обязательные поля**
   - **ID**, **Дисциплина** и **Название ДЗ** — обязательны. Строки без этих полей будут пропущены
   - Хотя бы один дедлайн (мягкий или жесткий) должен быть указан, иначе задание не будет отслеживаться
   - Если у задания только один дедлайн, записывайте его в **Жесткий Дедлайн** — так студенты точно не пропустят срок сдачи

3. **Уникальность заданий**
   - ID задания должен быть глобально уникален в обоих листах
   - Обновление всегда определяется по ID; название задания можно менять
   - При двух датах мягкий дедлайн не может быть позже жёсткого

### **Формат дат**

Бот поддерживает различные форматы дат. Рекомендуемые форматы:

- `15.12.2025 23:59` (день.месяц.год час:минуты)
- `15 декабря 2025`
- `2025-12-15`
- `15/12/2025`

**Важно:**
- Если время не указано, бот автоматически установит время **23:59**
- Даты интерпретируются в часовом поясе, указанном в настройках (по умолчанию: Europe/Moscow)

**Примеры корректных дат:**
- `15.12.2025` → 15 декабря 2025, 23:59
- `15.12.2025 18:00` → 15 декабря 2025, 18:00
- `2025-12-15` → 15 декабря 2025, 23:59

### **Синхронизация данных**

1. **Автоматическая синхронизация**
   - Бот периодически синхронизирует данные из `Google Sheets` (Раз в час)
   - При обнаружении изменений бот автоматически обновляет дедлайны и перепланирует уведомления

2. **Что происходит при синхронизации:**
   - Новые дедлайны добавляются в базу данных (определяются по отсутствию ID в базе)
   - Изменения в существующих дедлайнах обновляются (находятся по ID)
   - Уведомления перепланируются только при изменении дат дедлайнов
   - **Удалённые из корректно прочитанного листа дедлайны удаляются** вместе с зависимыми данными
   - Старые записи без указания листа-источника не удаляются автоматически и требуют ручной проверки

3. **Обработка ошибок:**
   - Если дисциплина не найдена, дедлайн пропускается с предупреждением в логах
   - Если дата не распознана, дедлайн пропускается с предупреждением
   - Ошибка чтения или разбора строк листа не интерпретируется как удаление записей из него
   - Перед записью можно выполнить `uv run python main.py sync --dry-run`

4. **Ручная синхронизация (для администраторов)**
   - В админ-панели (`/stats`) доступны две кнопки:
     - **🔄 Sync - Дедлайны** — синхронизация дедлайнов из листов "1_Курс_Дедлайны" и "2_Курс_Дедлайны"
     - **🔄 Sync - Дисциплины** — синхронизация дисциплин из листа "Дисциплины"
   - Также доступна команда `/full_sync` — запускает полную синхронизацию (дисциплины + дедлайны)

### **Как добавить новый дедлайн — коротко**

1. Откройте нужный лист (`1_Курс_Дедлайны` или `2_Курс_Дедлайны`)
2. Впишите следующий по порядку **ID** (1000, 1001, ... для 1 курса; 2000, 2001, ... для 2 курса)
3. Выберите **Дисциплину** из выпадающего списка
4. Заполните **Название ДЗ**
5. Укажите **Источник (Link)** — ссылку на задание
6. Заполните даты дедлайнов. Если дедлайн один — записывайте в **Жесткий Дедлайн**
7. При необходимости добавьте **Комментарий**
8. Дождитесь автоматической синхронизации (раз в час) или попросите администратора нажать **🔄 Sync - Дедлайны** в админ-панели

**Чтобы изменить дедлайн** — просто отредактируйте нужные ячейки в строке. ID не трогайте.

**Чтобы убрать дедлайн** — удалите строку целиком. Бот удалит задание при успешной синхронизации; повторное добавление создаст его заново.
