# Восстановление базы данных

## Проблема
База данных потеряла все таблицы. Ошибки типа:
```
relation "users" does not exist
relation "subjects" does not exist
```

## Решение

### Вариант 1: Через миграции Alembic (рекомендуется)

1. Загрузите обновленный код на сервер
2. Выполните миграцию:
```bash
docker exec -it hse_bot_app python main.py migrate
```

### Вариант 2: Через восстановление структуры

Если миграции не работают:
```bash
docker exec -it hse_bot_app python main.py restore
```

### Вариант 3: Автоматическое развертывание

Используйте скрипт развертывания:
```bash
chmod +x scripts/deploy.sh
./scripts/deploy.sh
```

## Проверка восстановления

После выполнения любого из вариантов проверьте:

1. Наличие таблиц в базе данных:
```bash
docker exec -it hse_bot_db psql -U postgres -d hse_bot_db -c "\dt"
```

2. Работу приложения:
```bash
docker logs hse_bot_app --tail 50
```

3. Перезапуск приложения:
```bash
docker-compose restart app
```
