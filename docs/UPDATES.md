## 🎉 Версия 1.0.0

**Дата релиза**: 23 Ноября 2025  
**Статус**: Стабильная версия

> **Большое обновление** с поддержкой отслеживания выполнения заданий и полноценной работой в групповых чатах.

### ✨ Основные изменения

#### ✅ **Отслеживание выполнения заданий**
- **Отметка заданий как выполненных** — пользователи могут отмечать выполненные задания прямо из списка дедлайнов через удобный интерфейс с кнопками-галочками
- **Автоматическая отмена уведомлений** — при отметке задания как выполненного, все запланированные уведомления для этого задания автоматически отменяются
- **Фильтрация выполненных заданий** — возможность скрыть или показать выполненные задания в списке дедлайнов

#### 💬 **Поддержка групповых чатов**
- **Полноценная работа в групповых чатах и супергруппах** — бот работает не только в личных сообщениях, но и в групповых чатах
- **Привязка чатов к предметам** — каждый чат и топик можно настроить на конкретный предмет для получения уведомлений
- **Независимые настройки уведомлений для чатов** — каждый чат имеет свои настройки напоминаний (аналогично личным настройкам пользователей)

### ➕ Дополнительно
- **Автоматическая деактивация** — пользователи и чаты автоматически деактивируются при блокировке бота
- **Улучшенная обработка ошибок** — все операции с Telegram API теперь обрабатываются безопасно через `Middleware`
- **Синхронизация с таблицей дисциплин** — настраивать дисциплины теперь можно без перезапуска (downtime) бота

- **Оптимизация производительности** — оптимизированы SQL запросы для работы с большим количеством пользователей
- **Умные уведомления** — пользователи не получают уведомления об обновлении дедлайнов для выполненных заданий

## 🎯 Версия 0.9.4

**Дата релиза**: 31 Октября 2025  
**Статус**: Бета версия

### ✨ Основные изменения

#### 📚 **Расширенная информация о предметах**
- **Ссылки на материалы** — добавлена поддержка ссылок на **`Wiki`**, плейлисты **`YouTube`** и **`VK`** для каждого предмета _(в разделе 📖 Дисциплины)_


#### 🔔 **Гибкие настройки уведомлений**

- **Режим сна (Do Not Disturb)** — настройка времени, когда уведомления будут приходить без звука (например, 23:00 - 08:30)
- **Управление уведомлениями об обновлениях** — появился переключатель для включения/отключения уведомлений об обновлении дедлайнов

#### 📝 **Улучшенное форматирование уведомлений**

- **Визуальное отображение изменений** — при обновлении дедлайна показывается новое значение и перечеркнутое старое
- **Различение новых и обновленных** — новые дедлайны отдельно от обновленных для лучшей навигации

## 🚀 Версия 0.9.3.1

**Дата релиза**: 26 Октября 2025
**Статус**: Бета-версия

### 🛠️ Инфраструктурные улучшения

#### ⚙️ Обновление зависимостей и инструментов
- **Переход на `uv`** — использование современного менеджера пакетов Python вместо `pip`
- **Интеграция `ruff`** — добавлен быстрый линтер и форматтер Python кода для поддержания качества кода

#### 📦 Улучшенное управление проектом
- **Makefile для удобных команд** — добавлен `Makefile` с командами `make run`, `make lint`, `make update` и другими
- **Упрощённая документация** — обновлена вся документация для использования `make` команд и `uv run`.

#### 🎯 Улучшенное логирование
- **Новая ротация логов** — теперь логи ротируются по неделям
- **Префиксы в логах** — `(U)` для пользователей, `(A)` для админов
- **Короткие сообщения** — все логи сокращены для удобства

**Пример:** 

```python
25-10-25 16:21:41 | INFO | deadlines:send_deadlines_list:106 | (U) 231585580 - Дедлайны на 15 дней
```

### ➕ Дополнительно

- **Очистка кода** — удалены неиспользуемые функции и исправлены импорты для улучшения читаемости.
- **Обновлён README** — добавлен раздел "Как это работает" с описанием потока работы системы.

## 🚀 Версия 0.9.3

**Дата релиза**: 29 Сентября 2025
**Статус**: Бета-версия

### ✨ Основные изменения

#### 🔔 Уведомления о новых и изменённых дедлайнах
- Как только в таблицах появляется новый дедлайн или обновляется существующий, **пользователи сразу получают отдельное уведомление**. Важные изменения теперь не проходят мимо.

#### ⚡ Быстрые действия в уведомлении
- В каждом уведомлении появилась кнопка **«📅 Дедлайны»** — один тап, и у пользователя перед глазами **актуальный список** заданий.

#### 📚 Обновлённый раздел помощи
- Раздел помощи стал **компактнее и понятнее**: добавили **легенды** для обозначений, **убрали лишнее** и сохранили только то, что помогает сориентироваться.

#### ⏱️ Точное расписание доставки
- Немного перфекционизма: уведомления приходят **ровно в 00** и **на каждую 15‑ю минуту** — аккуратно и красиво.

### ➕ Дополнительно

- **Ускорение запросов в БД** — быстрее выборки, меньше задержек при массовых рассылках.
- **Fail‑safe доставка** — даже если внешние сервисы дают сбой, бот **доставит сообщение** и пометит его соответствующей плашкой о задержке.

## 🎯 Версия 0.9.2

**Дата релиза**: 16 Сентября 2025
**Статус**: Бета-версия

### ✨ Основные изменения

#### 🔔 **Улучшения системы уведомлений**
- **Улучшенная обратная связь** - появились всплывающие плашки с понятными сообщениями об ошибках.
- **Валидация дублирования настроек** - предотвращение настройки одинаковых времен для первого и второго уведомления.
- **Оптмизированные уведомления** - большие «пачки» отправляются быстрее примерно в **~6 раз** (асинхронная обработка + батчинг).

### ⚙️ **Исправления**
- **Корректное планирование** - в случае, когда пользователь сначала выбирал предметы, а потом выполнял настройку, дедлайны не планировались. Исправлено.

#### 🧹 **Очистка кода**
- **Удалены излишние комментарии и логгирование** - код стал более читаемым и чистым

## 🎯 Версия 0.9.1

**Дата релиза**: 13 Сентября 2025
**Статус**: Бета-версия

### ✨ Основные изменения

#### 🌍 **Улучшенная настройка часового пояса**
- **Автоматическое определение по геолокации** вместо ручного ввода - отправьте местоположение для мгновенной настройки
- **Безопасность** - координаты не сохраняются, используются только для определения timezone

#### 📱 **Улучшения интерфейса**
- **Гиперссылки в дедлайнах** - названия заданий стали кликабельными ссылками
- **Дата с годом** - все даты теперь отображаются в формате `DD.MM.YYYY HH:MM`
- **Унифицированные уведомления** - единый формат для одного и нескольких дедлайнов
- **Цветные индикаторы** - 🟡 для мягких, 🔴 для жестких дедлайнов

#### ⚙️ **Технические улучшения**
- **Обновление статистики** - кнопка "Обновить статистику" теперь обновляет существующее сообщение
- **Очистка кода** - удалены неиспользуемые функции ручного ввода timezone
- **Новые зависимости** - добавлена библиотека `timezonefinder` для работы с геолокацией

### 🎯 **Примеры новых возможностей**

#### Новый формат дедлайнов:
```
📅 Дедлайны на 30 дней

1. Математика для анализа данных
📝 ДЗ_1_pro (кликабельная ссылка)
🔴 28.09.2024 23:59 (15 дн.)

2. Генеративные модели
📝 NLP / ImageGPT (кликабельная ссылка)
🟡 02.10.2024 23:59 (19 дн.)
```
