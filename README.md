# HSE AI Deadlines Bot

> 🤖 **Умный телеграм-бот для уведомлений о дедлайнах магистратуры ВШЭ (направление «Искусственный интеллект»)**
> 
> Автоматическая синхронизация с Google Sheets, персональные подписки, гибкие настройки уведомлений и админ-панель для управления.

**📦 Версия**: 0.9.1 (Бета) | **📅 Последнее обновление**: 13 Сентября 2025

## 🎯 Основные возможности

### 📚 **Управление подписками**
- **Выборочная подписка** на предметы по курсам (1-й и 2-й год)
- **Быстрое управление** подписками через инлайн-кнопки
- **Массовые операции**: отписка от всех предметов одной командой
- **Персонализация**: каждый пользователь видит только свои дедлайны

### ⏰ **Умные уведомления**
- **Гибкие настройки времени**: дни, часы до дедлайна.
- **Два типа напоминаний** на каждый дедлайн (например, за неделю и за день).
- **Разделение по типам**: мягкие и жёсткие дедлайны.
- **Автоматическое планирование** уведомлений при создании/изменении дедлайнов.
- **Группировка уведомлений** для удобства (несколько дедлайнов в одном сообщении).

### 📊 **Просмотр дедлайнов**
- **Персональный календарь** дедлайнов по подпискам
- **Гибкий период просмотра**: от 1 дня до месяца вперёд
- **Детальная информация**: название задания, ссылки, примечания
- **Временные метки**: точное время с учётом часового пояса

### 🔄 **Автоматическая синхронизация дедлайнов**
- **Интеграция с Google Sheets** для актуальных данных
- **Периодическая синхронизация** по расписанию
- **Ручной запуск** из админ-панели
- **Умное обновление**: только изменённые дедлайны
- **Автоматическое планирование** уведомлений при обновлении данных

### 👨‍💼 **Админ-панель**
- **Статистика системы**: пользователи, подписки, дедлайны
- **Управление синхронизацией**: ручной запуск, мониторинг
- **Массовые рассылки** с подтверждением
- **Просмотр логов** и мониторинг работы
- **Быстрые действия** для администраторов

## 🚀 Команды бота

### 👤 **Основные команды**
| Команда | Описание | Пример |
|---------|----------|---------|
| `/start` | Приветствие и регистрация | `/start` |
| `/help` | Справка по командам | `/help` |
| `/deadlines [N]` | Показать дедлайны на N дней | `/deadlines 7` |
| `/settings` | Настройки уведомлений | `/settings` |

### 📋 **Управление подписками**
| Команда | Описание | Пример |
|---------|----------|---------|
| `/sub` | Подписка на предметы | `/sub` |
| `/mysubs` | Мои подписки | `/mysubs` |
| `/unsub` | Отписка от предмета | `/unsub` |
| `/unsuball` | Отписка от всех предметов | `/unsuball` |

### 👨‍💼 **Админские команды** (только для администраторов)
| Команда | Описание | Пример |
|---------|----------|---------|
| `/stats` | Статистика бота | `/stats` |
| `/logs` | Просмотр логов | `/logs` |
| `/fast_sync` | Быстрая синхронизация | `/fast_sync` |
| `/broadcast` | Массовая рассылка | `/broadcast` |

## ⚙️ Настройки уведомлений

### 🔔 **Типы напоминаний**
- **Напоминание 1**: основное уведомление (по умолчанию: за 7 дней)
- **Напоминание 2**: дополнительное уведомление (по умолчанию: за 1 день)

### ⏱️ **Единицы времени**
- **Дни**: от 1 до 30 дней
- **Часы**: от 1 до 168 часов (неделя)
- **Минуты**: от 5 до 1440 минут (сутки)

### 🎛️ **Управление**
- **Включение/выключение** всех уведомлений
- **Индивидуальная настройка** каждого напоминания
- **Предустановленные варианты** (за неделю, за день, за час и т.д.)
- **Кастомные настройки** через текстовый ввод
- **Сброс к умолчанию** одной кнопкой

### 📱 **Примеры настроек**
```
Напоминание 1: за 7 дней
Напоминание 2: за 1 день

Или:

Напоминание 1: за 2 часа  
Напоминание 2: за 30 минут
```

## 🏗️ Архитектура системы

### 📊 **База данных**
- **PostgreSQL** с асинхронными операциями
- **Модели данных**:
  - `User` - пользователи бота
  - `Subject` - предметы/дисциплины
  - `Deadline` - дедлайны с мягкими и жёсткими сроками
  - `Subscription` - подписки пользователей на предметы
  - `UserNotificationSettings` - персональные настройки уведомлений
  - `ScheduledNotification` - запланированные уведомления

### 🔄 **Сервисы**
- **NotificationSchedulerService** - планирование уведомлений
- **ScheduledNotificationSender** - отправка уведомлений
- **NotificationService** - управление настройками
- **DataSyncer** - синхронизация с Google Sheets
- **HSEScheduler** - единый планировщик задач

### 📡 **Интеграции**
- **Google Sheets API** - источник данных о дедлайнах
- **Telegram Bot API** - интерфейс пользователя
- **APScheduler** - планировщик задач
- **SQLAlchemy** - ORM для работы с БД
