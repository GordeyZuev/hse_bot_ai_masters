# **🎓 ИИ: Бот-оповещатель**  

> 🤖 **Телеграм-бот для уведомлений о дедлайнах магистратуры «Искусственный интеллект» (НИУ ВШЭ)**
> 
> Автоматическая синхронизация с Google Sheets, персональные подписки, возможность отмечать выполненное и гибкие настройки уведомлений!

**📦 Версия**: 1.0.0 (Stable) | **📅 Будущее обновление**: 23 Ноября 2025

- Выборочная подписка на предметы по курсам
- Быстрое управление через инлайн-кнопки
- Персональные настройки для каждого пользователя
- **📚 Ссылки на материалы** — доступ к Wiki, плейлистам YouTube и VK для каждого предмета

### ⏰ **Умные уведомления**

- **🔔 Два напоминания на дедлайн** — основное и дополнительное
- **✨ Уведомления об изменениях** — только при изменении дат дедлайнов
- **📝 Показ изменений** — новое значение + перечеркнутое старое
- **📌 Разделение новых и обновленных** — отдельные секции
- **😴 Режим сна (Do Not Disturb)** — уведомления без звука в заданный период
- **🎛️ Управление уведомлениями об обновлениях** — можно отключить
- **🔄 Автоматическая группировка** — несколько задач в одном сообщении

### 💬 **Поддержка групповых чатов**
- **👥 Работа в группах и супергруппах** — бот работает не только в личных сообщениях
- **🏷️ Привязка к предметам** — каждый чат можно настроить на конкретный предмет
- **🧵 Поддержка топиков (Topics)** — уведомления приходят в соответствующие топики форумов
- **🔧 Независимые настройки чатов** — собственные параметры напоминаний для каждого чата

### 📊 **Просмотр дедлайнов**

- **✅ Отслеживание статуса** — отмечайте выполненные и скрывайте из списка

## 🔄 Как это работает

### 1️⃣ **Регистрация и настройка**
Пользователь запускает бота командой `/start`, после чего выбирает интересующие предметы для подписки и настраивает параметры уведомлений (когда и как часто напоминать).

### 2️⃣ **Синхронизация данных**
Каждый час бот автоматически синхронизирует данные с Google Sheets, извлекая актуальную информацию о дедлайнах. При обнаружении новых или изменённых дедлайнов они сохраняются в базу данных.

### 3️⃣ **Планирование уведомлений**
После синхронизации система автоматически создаёт расписание уведомлений для каждого пользователя на основе его подписок и настроек. Уведомления группируются и отправляются по расписанию (каждые 15 минут).

### 4️⃣ **Мгновенные уведомления об изменениях**
Когда в таблице появляется новый дедлайн или изменяется существующий (только даты дедлайнов), все подписанные пользователи сразу получают отдельное уведомление с деталями изменения. Новые дедлайны отображаются отдельно от обновленных, а изменения визуально показаны с перечеркнутыми старыми значениями.

### 5️⃣ **Доставка напоминаний**
В назначенное время (например, за 7 дней и за 1 день до дедлайна) бот отправляет пользователю уведомления со списком предстоящих дедлайнов и кнопкой для быстрого просмотра актуального списка. Выполненные задания автоматически исключаются из уведомлений.

### 6️⃣ **Отслеживание статуса заданий**
Пользователь может отмечать задания как выполненные прямо из списка дедлайнов. При отметке задания:
- Все запланированные уведомления по этому заданию автоматически отменяются
- Выполненные задания можно скрыть из списка или показать отдельно
- При снятии отметки уведомления автоматически перепланируются

### 7️⃣ **Интерактивное управление**
Пользователь может в любой момент просмотреть свои дедлайны, изменить подписки, обновить настройки уведомлений, отметить выполненные задания или получить помощь через команды бота.

## ⚙️ Настройки уведомлений

### 🔔 **Типы напоминаний**
- **Напоминание 1**: основное уведомление (по умолчанию: за 7 дней)
- **Напоминание 2**: дополнительное уведомление (по умолчанию: за 1 день)

### ⏱️ **Единицы времени**
- **Дни**: от 1 до 30 дней
- **Часы**: от 1 до 168 часов (неделя)
- **Минуты**: от 5 до 1440 минут (сутки)

### 🎛️ **Управление**
- **Включение/выключение** всех уведомлений
- **Управление уведомлениями об обновлениях** — отдельный переключатель для включения/отключения уведомлений об обновлении дедлайнов
- **Режим сна (Do Not Disturb)** — настройка времени, когда уведомления будут приходить без звука (например, 23:00 - 08:30)
- **Индивидуальная настройка** каждого напоминания
- **Предустановленные варианты** (за неделю, за день, за час и т.д.)
- **Кастомные настройки** через текстовый ввод
- **Сброс к умолчанию** одной кнопкой

### 📱 **Примеры настроек**
```
Напоминание 1: за 7 дней
Напоминание 2: за 1 день

Или:

Напоминание 1: за 2 часа  
Напоминание 2: за 30 минут
```

## 🏗️ Архитектура системы

### 📊 **База данных**
- **PostgreSQL** с асинхронными операциями
- **Модели данных**:
  - `User` - пользователи бота
  - `Subject` - предметы/дисциплины (с поддержкой ссылок на материалы)
  - `Task` - задания/дедлайны с мягкими и жёсткими сроками
  - `Subscription` - подписки пользователей на предметы
  - `UserNotificationSettings` - персональные настройки уведомлений (с режимом сна и управлением обновлениями)
  - `ScheduledNotification` - запланированные уведомления для пользователей (связь с `Task`)
  - `TaskUserStatus` - статус выполнения заданий пользователями
  - `ChatGroup` - групповые чаты с привязкой к предметам
  - `ChatScheduledNotification` - запланированные уведомления для чатов (связь с `Task`)

### 🔄 **Сервисы**
- **NotificationSchedulerService** - планирование уведомлений для пользователей (исключает выполненные задания)
- **ScheduledNotificationSender** - отправка уведомлений пользователям
- **TaskStatusService** - управление статусом выполнения заданий (отметка выполненных/снятие отметки)
- **ChatNotificationSchedulerService** - планирование уведомлений для групповых чатов
- **ChatNotificationSender** - отправка уведомлений в групповые чаты и топики
- **ChatService** - управление групповыми чатами
- **NotificationService** - управление настройками
- **DataSyncer** - синхронизация с Google Sheets (с умным определением изменений)
- **HSEScheduler** - единый планировщик задач

### 📡 **Интеграции**
- **Google Sheets API** - источник данных о заданиях/дедлайнах
- **Telegram Bot API** - интерфейс пользователя
- **APScheduler** - планировщик задач
- **SQLAlchemy** - ORM для работы с БД
