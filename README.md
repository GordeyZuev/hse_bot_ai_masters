# Бот - оповещатель ИИ

Телеграм бот для уведомлений о дедлайнах студентов магистратуры ВШЭ по направлению "Искусственный интеллект". Бот интегрируется с Google Sheets для синхронизации данных о дедлайнах и предоставляет полнофункциональную систему подписок и уведомлений.

## 🚀 Основные возможности

- **Система подписок** - подписка на предметы и управление подписками
- **Уведомления о дедлайнах** - настраиваемые уведомления (минимум за 30 минут до дедлайна)
- **Просмотр дедлайнов** - отображение дедлайнов с цветовой индикацией по срочности
- **Настройки уведомлений** - гибкая настройка времени и типов уведомлений
- **Административная панель** - статистика, массовые рассылки, управление логами
- **Синхронизация с Google Sheets** - автоматическое обновление данных о дедлайнах
- **Многопользовательская система** - поддержка неограниченного количества пользователей

## 🤖 Команды бота

### Пользовательские команды

| Команда | Описание |
|---------|----------|
| `/start` | Запуск бота и главное меню |
| `/help` | Подробная справка по использованию |
| `/sub` | Подписаться на предмет |
| `/unsub` | Отписаться от предмета |
| `/unsuball` | Отписаться от всех предметов |
| `/mysubs` | Показать все активные подписки |
| `/deadlines [N]` | Дедлайны на N дней (по умолчанию 15) |
| `/settings` | Настройки уведомлений |

### Административные команды

| Команда | Описание | Доступ |
|---------|----------|--------|
| `/admin` | Административная панель | Только админы |
| `/stats` | Статистика использования бота | Только админы |
| `/fast_sync` | Быстрая мгновенная синхронизация с Google Sheets | Только админы |
| `/broadcast` | Массовая рассылка сообщений | Только админы |
| `/logs` | Получить файлы логов | Только админы |

#### Админ-панель
Доступ к админ-панели через команду `/stats`:
- **📊 Статистика** - Подробная статистика использования бота
- **🔄 Синхронизация** - Мгновенная синхронизация данных с Google Sheets
- **📢 Broadcast** - Массовая рассылка сообщений всем пользователям
- **📄 Сегодняшние логи** - Получение файлов логов за текущий день

## 🔄 Функциональность

### Подписки на предметы
1. Используйте `/sub` для выбора курса (1 или 2)
2. Выберите предметы для подписки
3. Управляйте подписками через `/mysubs`, `/unsub`, `/unsuball`

### Настройка уведомлений
1. Откройте `/settings`
2. Настройте до 2 уведомлений на пользователя
3. Выберите время: за N дней/часов/минут до дедлайна
4. Включайте/выключайте уведомления по необходимости

### Просмотр дедлайнов
- `/deadlines` показывает дедлайны только по подписанным предметам
- Поддерживаются мягкие и жесткие дедлайны
- Отображается время до дедлайна
- Ссылки на задания (если есть)

## ⚙️ Автоматические процессы

### Синхронизация данных
- Каждый час синхронизируются данные из Google Sheets
- Обновляются дедлайны и информация о предметах
- Удаляются устаревшие дедлайны
- **Мгновенная синхронизация**: Администраторы могут запустить синхронизацию вручную через админ-панель

### Система уведомлений
- Каждые 10 минут проверяются приближающиеся дедлайны
- Отправляются персонализированные уведомления
- Ведется лог отправленных уведомлений

### Очистка данных
- Ежедневно в 3:00 очищаются старые логи
- Удаляются записи старше 30 дней

## ⚙️ Установка и настройка

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd hse_bot_ai_masters
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Создайте файл `src/config/.env` со следующими переменными:

```env
# Telegram Bot
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_IDS=123456789,987654321  # ID администраторов через запятую

# Database
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/hse_bot

# Google Sheets
GOOGLE_SHEETS_URL=https://docs.google.com/spreadsheets/d/your_sheet_id/edit
GOOGLE_CREDENTIALS_PATH=path/to/your/credentials.json

# External Links
FCS_WIKI_URL=https://wiki.cs.hse.ru/
GOOGLE_SHEETS_LINK=https://docs.google.com/spreadsheets/d/your_sheet_id/edit

# Logging
LOG_LEVEL=INFO
LOG_FILE_PATH=logs/bot.log
SYNC_LOG_FILE_PATH=logs/sync.log

# Timezone
TIMEZONE=Europe/Moscow

# Notification Settings
NOTIFICATION_DAYS_BEFORE=3,1,0  # За сколько дней уведомлять (устаревшее)
NOTIFICATION_TIME=09:00  # Время уведомлений (HH:MM, устаревшее)
SYNC_INTERVAL_HOURS=1    # Интервал синхронизации в часах
NOTIFICATION_CHECK_MINUTES=5  # Интервал проверки уведомлений в минутах
```

### 4. Настройка базы данных

```bash
# Создание миграций (если нужно)
alembic revision --autogenerate -m "Initial migration"

# Применение миграций
alembic upgrade head
```

### 5. Настройка Google Sheets API

1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включите Google Sheets API
3. Создайте Service Account и скачайте JSON-файл с ключами
4. Укажите путь к файлу в переменной `GOOGLE_CREDENTIALS_PATH`
5. Предоставьте доступ к таблице для email из Service Account

## 🏗️ Архитектура

### Основные компоненты

1. **Bot Layer** (`src/bot/`)
   - Обработчики команд и callback'ов
   - FSM для управления состояниями пользователя
   - Middleware для автоматического управления пользователями
   - Сервисы для бизнес-логики бота

2. **Core Layer** (`src/core/`)
   - Модели данных (SQLAlchemy)
   - Менеджер базы данных
   - Система синхронизации с Google Sheets
   - Планировщик задач

3. **Utils Layer** (`src/utils/`)
   - Система логирования
   - Вспомогательные утилиты

### Паттерны проектирования

- **Service Layer** - бизнес-логика вынесена в отдельные сервисы
- **Repository Pattern** - абстракция работы с базой данных
- **Middleware Pattern** - обработка запросов через промежуточное ПО
- **FSM (Finite State Machine)** - управление состояниями пользователя
- **Dependency Injection** - внедрение зависимостей через middleware

### База данных

Используется PostgreSQL с SQLAlchemy 2.0 (async). Основные таблицы:

- `users` - пользователи бота
- `subjects` - предметы
- `deadlines` - дедлайны
- `subscriptions` - подписки пользователей
- `notifications` - история уведомлений

## 💾 Система бэкапов

### Быстрый старт

#### 1. Настройка автоматического ежедневного бэкапа
```bash
# Настройка бэкапа на 02:00 каждый день
./scripts/setup-backup-cron.sh

# Или на определенное время (например, 03:30)
./scripts/setup-backup-cron.sh -t 03:30

# Показать текущие cron задачи
./scripts/setup-backup-cron.sh --show
```

#### 2. Ручное создание бэкапа
```bash
# Создание бэкапа
./scripts/backup-db.sh
```

#### 3. Восстановление из бэкапа
```bash
# Показать доступные бэкапы
ls -la backups/

# Восстановить из бэкапа
./scripts/restore-db.sh backups/hse_bot_db_backup_20240101_120000.sql.gz

# Принудительное восстановление без подтверждения
./scripts/restore-db.sh backup.sql.gz --force

# Восстановление с пересозданием базы данных
./scripts/restore-db.sh backup.sql.gz --drop-existing
```

### Особенности системы бэкапов

- **Автоматическое сжатие** - все бэкапы автоматически сжимаются gzip
- **Ротация бэкапов** - по умолчанию хранятся бэкапы за последние 7 дней
- **Проверка целостности** - автоматическая проверка размера и валидности бэкапов
- **Логирование** - все операции логируются в `logs/backup.log`
- **Уведомления** - опциональные уведомления об ошибках через Telegram
- **Docker-совместимость** - работа с базой данных в Docker контейнере

### Конфигурация бэкапов

Добавьте в файл `src/config/.env`:

```env
# Количество дней для хранения бэкапов (по умолчанию: 7)
BACKUP_RETENTION_DAYS=7

# Уведомления об ошибках (опционально)
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_ADMIN_CHAT_ID=your_admin_chat_id
```

### Расположение бэкапов

- **Директория**: `backups/`
- **Формат имени**: `hse_bot_db_backup_YYYYMMDD_HHMMSS.sql.gz`
- **Логи**: `logs/backup.log`, `logs/restore.log`
