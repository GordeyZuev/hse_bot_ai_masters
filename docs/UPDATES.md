## 🚀 Версия 0.9.0 (Текущая)

**Дата релиза**: 13 Сентября 2025
**Статус**: Бета-версия

### ✨ Основные изменения

#### 🔔 **Новая система уведомлений**
- Уведомления на мягкие и жёсткие дедлайны
- Надёжная доставка с повторными попытками
- Автоматическое перепланирование при изменениях
- Группировка уведомлений в одно сообщение

#### ⏰ **Персональные настройки**
- Гибкие настройки времени (дни, часы, минуты)
- Предустановленные и кастомные варианты
- Поддержка часовых поясов
- Интерактивный интерфейс настроек

#### 🗄️ **Архитектурные улучшения**
- Новые таблицы БД для уведомлений и настроек
- Переработанный планировщик задач
- Асинхронная обработка
- Улучшенная производительность

## 🎯 Версия 0.8.0

**Дата релиза**: 3 Сентября 2025  
**Статус**: Бета-версия

### ✨ Основные изменения

#### 🏗️ **Базовая архитектура**
- Модульная структура (bot, core, utils)
- Асинхронная архитектура
- Docker поддержка
- PostgreSQL с SQLAlchemy

#### 🤖 **Основной функционал**
- Команды бота (`/start`, `/help`, `/deadlines`, `/sub`, `/unsub`)
- Система подписок на предметы
- Просмотр дедлайнов
- Базовая админ-панель

#### 🔄 **Интеграции**
- Синхронизация с Google Sheets
- Автоматическое обновление данных
- Базовая система уведомлений
- Структурированное логирование
