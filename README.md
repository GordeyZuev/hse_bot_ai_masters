# HSE Bot AI Masters - Telegram Bot

Телеграм бот для уведомлений о дедлайнах студентов магистратуры ВШЭ по направлению "Искусственный интеллект".

## Структура проекта

```
├── src/                           # Исходный код
│   ├── bot/                      # Телеграм бот
│   │   ├── handlers/            # Обработчики команд
│   │   ├── middlewares/         # Промежуточное ПО
│   │   └── services/            # Сервисы бота
│   ├── core/                    # Основная логика
│   │   ├── database/            # Работа с базой данных
│   │   │   ├── __init__.py
│   │   │   └── database.py      # DatabaseManager, db_manager
│   │   ├── models/              # Модели данных
│   │   │   ├── __init__.py
│   │   │   ├── models.py        # SQLAlchemy модели
│   │   │   └── subjects_data.py # Данные предметов
│   │   └── sync/                # Синхронизация данных
│   │       ├── __init__.py
│   │       ├── data_syncer.py   # Синхронизация с Google Sheets
│   │       ├── gsheets_syncer.py # Работа с Google Sheets API
│   │       └── scheduler.py     # Планировщик задач
│   ├── utils/                   # Утилиты
│   │   ├── __init__.py
│   │   └── logger.py           # Настройка логирования
│   └── config/                  # Конфигурация
│       ├── __init__.py
│       └── .env                # Переменные окружения
├── logs/                        # Файлы логов
├── alembic/                     # Миграции базы данных
├── main.py                      # Точка входа приложения
├── requirements.txt             # Зависимости Python
└── README.md                    # Этот файл
```

## Функционал бота

### Пользовательские команды:
- `/start` - Запуск бота, короткая справка
- `/help` - Подробная информация о боте
- `/sub` - Подписаться на предмет
- `/unsub` - Отписаться от предмета
- `/unsuball` - Отписаться от всех предметов
- `/mysubs` - Показать все подписки
- `/deadlines [N]` - Дедлайны на N следующих дней (по умолчанию N=15)
- `/settings` - Настройки уведомлений

### Административные команды:
- `/stats` - Статистика использования
- `/broadcast` - Массовая рассылка

## Запуск

```bash
# Установка зависимостей
pip install -r requirements.txt

# Одиночная синхронизация данных
python main.py sync

# Запуск планировщика (по умолчанию)
python main.py scheduler
```

## Конфигурация

Настройки находятся в файле `src/config/.env`:

- `BOT_TOKEN` - Токен Telegram бота
- `DATABASE_URL` - URL подключения к PostgreSQL
- `GOOGLE_SHEETS_URL` - URL Google Sheets с дедлайнами
- `LOG_LEVEL` - Уровень логирования (INFO, DEBUG, ERROR)

## Архитектура

Проект организован по принципу разделения ответственности:

- **src/bot/** - Логика телеграм бота (будет добавлена)
- **src/core/** - Основная бизнес-логика
- **src/utils/** - Вспомогательные утилиты
- **src/config/** - Конфигурация приложения

Каждый модуль имеет свой `__init__.py` для удобного импорта компонентов.
