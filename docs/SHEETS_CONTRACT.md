# Контракт Google Sheets

## Дисциплины

Обязательные колонки: `ID`, `Дисциплина`, `Active`. Поддерживаемые дополнительные колонки:
`Курс`, `Модуль`, `LEAP`, `YouTube`, `Ya Disk`.

- `ID` — уникальный положительный integer.
- Для импорта достаточно ID и названия; пустой курс допустим.
- `Модуль` — список через запятую: `1, 3` означает именно модули 1 и 3.
- `Active=TRUE` включает дисциплину; `FALSE` и пустая ячейка выключают.
- Пустая URL-ячейка удаляет сохранённую ссылку.
- Принимаются только HTTP/HTTPS URL.
- Некорректные `Active`, `Модуль` или URL пропускают всю строку и сохраняют
  прежние значения в БД. При ошибках строк автоматическая архивация дисциплин
  не выполняется.

## Дедлайны

Колонки: `ID`, `Дисциплина`, `Название ДЗ`, `Источник (Link)`,
`Мягкий Дедлайн`, `Жесткий Дедлайн`, `До мягкого`, `До жесткого`,
`Комментарий`.

Валидная строка содержит глобально уникальный ID, название задания, точное название
существующей дисциплины и хотя бы одну дату. Можно указывать soft, hard или обе даты;
при двух датах soft не может быть позже hard. Вычисляемые колонки `До ...` бот не
импортирует.

Удалённое из корректно прочитанного листа задание удаляется физически. При ошибках
чтения или разбора строк удаление из этого листа не выполняется. Старые задания без
`source_sheet` сопоставляются по глобальному ID; отсутствующие во всех листах
удаляются только при полностью успешном чтении всех листов и отсутствии ошибок строк.

Перед применением изменений используйте:

```bash
uv run python main.py sync --dry-run
```

Команда выводит лист, номер строки и ID каждой ошибки; при любой ошибке данных
завершается с ненулевым кодом. Неполные строки заданий с названием, но без обоих
дедлайнов считаются ошибкой, а не готовым заданием.
